# Análise das informações do projeto

1. Você envia as informações (texto, arquivos ou imagens).
2. Eu comparo cada ponto com o que já existe no sistema: login, cadastro, ordens de serviço, reservas CFTV, reparos, supervisão, análise de perdas e PDFs.
3. Entrego uma lista com três grupos: o que funciona, o que não funciona ou está incompleto, e sugestões com prioridade.
4. Nenhuma alteração é feita no sistema até você aprovar as correções.
